# Mashal Khan — Civil Engineering Student Portfolio

A multi-page static website built with HTML, CSS, and vanilla JavaScript. It does not require React, TypeScript, Vite, npm, or a build step.

Pages: Home, About, Academics, Courses, Projects, Journal, and Contact.

Features include a persistent theme toggle, mobile navigation, searchable course workspaces, browser-local checklist and roadmap progress, a downloadable text profile, print/save as PDF, and clickable project/journal details.

Open index.html directly or serve the folder with any static HTTP server. GitHub Actions publishes the static site to GitHub Pages.
