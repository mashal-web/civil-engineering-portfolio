# Mashal Khan — Minimal Civil Engineering Portfolio

A multi-page civil engineering student portfolio built around a restrained light neumorphic interface, architectural typography, structured course resources and minimal dependencies.

## Stack
- Semantic HTML pages
- External CSS
- No JavaScript or framework required for content or navigation
- No framework, package manager, remote font or third-party runtime
- GitHub Pages deployment through GitHub Actions

## Pages
Home, About, Academics, Courses & Skills, Projects, Journal and Contact. Individual project and journal articles live in their respective directories.

## Local preview
Open `index.html` in a browser, or serve the folder with any simple static file server. There is no build step.

## Deployment
Push to `main`. The workflow validates required pages, local links, in-page anchors, metadata, accessibility basics and navigation structure, then publishes the authored pages—including the custom 404 page—to GitHub Pages.

## Performance and accessibility
The site is HTML-first, uses system fonts, has no client-side JavaScript dependency, includes skip links and visible keyboard focus, and uses responsive CSS with reduced-motion and print support. Performance budgets must be verified with actual browser measurements; architecture alone does not guarantee scores.

## Content integrity
Projects and technical drawings are student learning examples. They are not construction-ready designs or professional engineering advice. Add grades, credentials and project results only when verified.
