# Civil Engineering Portfolio — Mashal Khan

React + TypeScript + Vite starter for a student portfolio. It is separate from the existing `mashal-portfolio` repository.

## Run locally
Requirements: Node.js 20.19+ or 22.12+, and npm.

```bash
npm install
npm run dev
```

Verify production build:
```bash
npm run build
npm run preview
```

## Before publishing
- Confirm the exact university/program wording. Only state current SSUET enrollment if it is confirmed.
- Replace `your-email@example.com` with a public email address you intend to publish.
- Replace planned project entries with genuine work as you complete it. They are explicitly labelled as placeholders.
- Add real journal entries and certificates only when available.
- Test mobile and desktop layouts and run `npm run build`.

## Deployment
The Vite config uses relative asset paths. Configure GitHub Pages Actions or deploy to a static host such as Vercel or Netlify.
